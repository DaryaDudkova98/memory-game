# Memory game

### Goal

Create a memory matching game — the player flips cards and memorizes their positions to find all the pairs in as few moves as possible.

---

### Skills Applied

- Generating HTML markup with JavaScript.
- Splitting game logic into functions with clear responsibilities.
- Working with a collection of cards and randomizing their order.
- Keeping game state, event handling, and UI rendering in sync.
- Handling repeated user actions and deferred state updates.
- Building reusable application components.
